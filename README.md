Osmanlı İmparatorluğu'nun kuruluşundan (1299 - Osman Gazi) son dönemine (1922 - Mehmed Vahdeddin) kadar tahta geçen **36 Osmanlı Padişahı** ve **Fetret Devri** hakkında derli toplu bilgiler sunan, saf HTML & CSS ile hazırlanmış açık kaynak web ansiklopedisi.

---

## 📖 Projenin Hikayesi

> 💡 **Bir Lise 10. Sınıf Proje Ödevinden Açık Kaynağa:**  
> Bu proje, lise 10. sınıf döneminde tarih ve web tasarımı ödevi olarak saf HTML ve CSS kullanılarak hazırlanmıştır.  
> 
> Web geliştirmeye yeni adım atan genç arkadaşlara saf (Vanilla) HTML/CSS ile nasıl sayfa mimarisi ve gezinti (navigation) kurulabileceğini göstermek, tarih ödevi hazırlayan öğrencilere derli toplu açık kaynak bir kaynak sunmak ve nostaljik bir anıyı geleceğe taşımak amacıyla açık kaynak olarak paylaşılmıştır.

---

## ✨ Özellikler

- 📜 **Kronolojik Sıralama:** Osman Gazi'den VI. Mehmed Vahdeddin'e kadar tüm padişahlar saltanat yıllarına göre sıralanmıştır.
- 🔄 **Bağlantılı Gezinti (Navigation):** Her padişah sayfasında bir önceki ve bir sonraki padişaha kolayca geçiş sağlayan bağlantı tablosu.
- 🖼️ **Görsel Arşiv:** Her padişahın yüksek kaliteli portresi yuvarlak çerçeve estetiğiyle (`rounded-image`) sunulmaktadır.
- 👨‍👩‍👧‍👦 **Aile Ağacı Bilgileri:** Her padişahın eşleri, erkek çocukları (şehzadeleri) ve kız çocukları ayrıntılı listelenmiştir.
- ⚡ **Sıfır Kurulum & Bağımlılık:** `npm`, `node` veya herhangi bir veritabanı gerektirmez. `Anasayfa.html` dosyasına çift tıklayarak anında çalışır.

## 📂 Dosya Yapısı

```bash
osmanli-padisahlari/
├── Anasayfa.html              # Tüm padişahların listelendiği ana vitrin tablosu
├── styles.css                 # Klasik, temiz CSS stil dosyası
├── resimler/                  # Padişah portreleri ve Osmanlı arması/logoları
├── osman-gazi.html            # I. Padişah - Osman Gazi
├── orhan-gazi.html            # II. Padişah - Orhan Gazi
├── ...                        # Diğer tüm padişah sayfaları
└── README.md                  # Proje dokümantasyonu
```

## 🚀 Nasıl Çalıştırılır?

Projeyi çalıştırmak için hiçbir terminal komutu veya paket yöneticisi gerekmez:

1. Repoyu bilgisayarınıza indirin (veya klonlayın):
   ```bash
   git clone https://github.com/7EMRE1905/osmanli-padisahlari.git
   ```
2. Klasörün içindeki `Anasayfa.html` dosyasına çift tıklayın.
3. Web tarayıcınızda dilediğiniz padişahı incelemeye başlayın!
